### Task 5: Variance % blank on a tiny base

When |base| is below the metric's percentage floor (materiality abs / 10, i.e. 500 000 NOK for NOK metrics), the
variance % is empty in both the model (`None`) and Excel. The formula becomes
`IF(ABS(base)<floor,"",(cur-base)/ABS(base))`.
- **Where the floor lives.** Write it in a labelled helper cell, never as a constant inside the formula
  (tn-formelstil BLOCK). The answer sheet gets a small "Thresholds" note row holding the floor per metric used,
  and the formula references it. If that is too heavy, put the floor cell once per block header row. Choose the
  simplest layout that passes `xl_tidy` with zero BLOCK findings, and test that.
- **Stock and ratio metrics** (FTE, %) use their own floor. If a metric has none, there is no floor.

**Goldens.**
1. Add `testset candidate --offline <ids>`, which writes `candidate.json` from a replay.
2. Run it for every case and diff the candidates against the goldens.
3. If the only differences are `Variance %` → `None` on lines whose |last year| is below the floor, run `approve`
   on those cases and list each changed line in the commit message.
4. Any other difference: STOP and report.
